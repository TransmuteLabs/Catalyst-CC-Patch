# Корпус пристинных образов для свипа: метка (аргумент sweep.sh) и версия.
#
# ОДИН список на два инструмента: tools/sweep.sh берёт отсюда, что мерить, а
# tools/fetch-corpus.sh -- что докачивать. Два списка разошлись бы на первой же
# новой версии: свип отказывался бы из-за отсутствующего образа, а наполнитель
# не знал бы, что качать.

# Третье поле -- sha256 образа, каким его отдаёт реестр. Пин ставится один раз и
# ТОЛЬКО по байтам реестра: если образ уже лежит в корпусе, а пина нет,
# наполнитель всё равно качает версию и сверяет -- иначе эталоном стало бы то,
# что никто не проверял. Дальше пин только ПРОВЕРЯЕТСЯ: и наполнителем, и
# свипом перед прогоном. Корпус --
# доказательная база, а не просто файлы: усечённый или подменённый образ даёт
# измерение, неотличимое от настоящего. Прецедент уже был -- зелёная сводка
# поверх загрязнённого артефакта (см. шапку tools/sweep.sh). Слово «-» вместо
# цифр означает «ещё не записан».
#
# Что здесь должно быть: по одной версии на каждую ЗАПИСЬ бандла, которую наши
# якоря обязаны понимать, плюс граничные версии, на которых запись менялась.
#   233..241 -- единый файл, CJS-обёртки

#   248..    -- настоящие ESM-чанки, import.meta.require("/$bunfs/root/chunk-*")
