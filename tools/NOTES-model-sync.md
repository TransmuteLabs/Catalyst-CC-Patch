abandon после публикации снимает каталог по пути только при совпадении (dev, ino); неподтверждённый путь оставляется, owner снят по дескриптору — пустой каталог снимает просрочка.

Уборка просроченных staging (`<lock>.new.*`) может снять `owner` у staging писателя, замершего дольше срока просрочки. Исходы безопасны: каталог снят целиком — публикация получает ENOENT и отказывает rc 5; каталог опубликован без `owner` — держатель живёт heartbeat'ом, после его смерти пустой каталог снимает просрочка как формат до v2. Свой staging узнаётся по имени записи в каталоге, не по написанию пути.
