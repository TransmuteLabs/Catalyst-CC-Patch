# ИНЕРТНЫЕ правки tweakcc: те, что на названной версии не делают НИЧЕГО.
# Два знака, две причины (см. src/index.tsx форка):
#   ⊘  версия правку не несёт вовсе -- её `versionCondition` ложен, и правка
#      даже не пробуется;
#   ≡  правка ПРОБОВАЛАСЬ, ошибки не вернула и не изменила ни байта.
# Оба входят в число ПОПЫТОК (tools/tweakcc-expected-applied.txt объявляет
# размер реестра), но не в число легших и не в множество выключенных.
#
# У ДВУХ ЗНАКОВ РАЗНЫЕ ВЛАДЕЛЬЦЫ. Порядок проверок в форке -- версия, затем
# конфиг, затем исполнение (src/patches/index.ts: `versionCondition` ложен ->
# ⊘; `condition` ложен -> ○; и только потом ранний возврат самой правки -> ≡):
#   ⊘ -- пара «версия апстрима + реестр форка». Конфиг машины на исход не
#     влияет вовсе: до него проверка не доходит.
#   ≡ -- ТРОЙКА «версия + реестр форка + конфиг дома». Знак достижим ТОЛЬКО
#     там, где конфиг оператора оставил правку включённой: выключенная
#     отсекается раньше исполнения и печатается как ○.
# Дом файла -- кит, потому что имена приносят версия и реестр форка; доля
# третьего владельца учтена ослаблением стороны «объявлено, но не измерено»
# ниже. Множество ВЫКЛЮЧЕННЫХ правок (catalyst-expected-off.txt) живёт в доме
# tweakcc потому, что владелец у него ОДИН -- конфиг КОНКРЕТНОЙ МАШИНЫ.
#
# Объявляются ИМЕНА, а не числа. Равный итог не означает равного состава:
# обмен одного инертного имени на другое счёт не двигает, и дверь на числе
# такую подмену пропускает молча. Прежняя редакция этого файла объявляла число
# ⊘ -- заменено поимённым набором по этой причине.
#
# Знак ≡ НЕ означает промах локатора. В форке есть умышленный ранний возврат
# «на этой версии делать нечего» (worktreeMode.ts:29, mcpStartup.ts:130), и
# безусловный отказ на ≡ краснил бы здоровый прогон -- замерено на 2.1.261.
#
# Дверь ДВУСТОРОННЯЯ по каждому знаку (claude-patch-all.sh,
# __tw_inert_check_sign):
#   измерено, но не объявлено -- форк перестал что-то делать на этой версии, и
#     без двери это прошло бы молча;
#   объявлено, но не измерено -- запись пережила свою причину и продолжала бы
#     прикрывать будущую пропажу.
# Односторонняя сверка сделала бы из строки бессрочную индульгенцию -- ровно
# то, от чего кит уже лечил соседние объявления.
#
# У знака ≡ вторая сторона ослаблена РОВНО на исход ○ -- по третьему владельцу:
# оператор выключил тумблер в интерфейсе форка, это штатное действие, а сам
# исход гейтится ДВУСТОРОННЕ дверью множества выключенных, чей дом -- машина
# (catalyst-expected-off.txt). Всякий ДРУГОЙ исход отказывает: измерено ✓ или
# ✗ -- «правка снова работает»; имени нет в выводе форка вовсе -- «ушла из
# реестра форка»; имя измерено под ДРУГИМ знаком -- «объявлено как одно,
# измерено как другое». У знака ⊘ послабления нет и быть не может: его
# владельцы отказывают обе стороны одинаково.
#
# Поля через ТАБУЛЯЦИЮ: <версия> <знак ⊘|≡> <имя правки> <причина>.
# Строки «#» и пустые пропускаются, поля тримятся, BOM снимается. Одна пара
# «версия+знак+имя» -- одна строка (дубль дверь отвергает). Поле причины
# ОБЯЗАТЕЛЬНО: пустое либо оставленный дословно текст-заготовка «<причина>» --
# отказ. Так строку нельзя вклеить, не написав, откуда она взялась.
#
# Набор к соседней версии НЕ ПЕРЕНОСИТСЯ: данные апстрима у каждой свои. Если
# строк под версию нет, а инертные измерены, дверь печатает готовые к вклейке
# строки -- вписывать следует ИЗМЕРЕННОЕ, назвав, откуда оно взято.
