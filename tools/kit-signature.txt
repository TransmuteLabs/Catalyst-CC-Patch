# Подпись кита: по каким файлам каталог опознаётся как НАШ комплект.
#
# Зачем она есть. Три инструмента выводят корень кита из пути собственного
# файла и КОПИРУЮТ этот корень ЦЕЛИКОМ: tools/sweep.sh (и запускает из копии
# конвейер), tools/corpus-tools-bench.sh, tools/docnum-bench.py. Позванный из
# копии вне кита, такой инструмент получает корнем произвольный каталог --
# замерено, как корнем стала файловая система и 3.8 ГБ уехали в tmp до ручной
# остановки. Поэтому каждый из троих проверяет подпись ДО первой копии и
# отказывает кодом 2 «прибор не может мерить» -- это отказ прибора, не вердикт
# о продукте.
#
# Почему перечень лежит ЗДЕСЬ, а не в каждом из троих. Раньше все три несли
# свою копию этих имён. Такой перечень -- проекция: расходится молча, и
# опознание у троих становится разным, причём слабейший определяет, какой
# чужой каталог будет скопирован целиком. Перечень, живущий рядом со своим
# домом, обязан либо читаться из дома, либо не существовать; здесь выбрано
# первое, и дом -- этот файл.
#
# Чем доказано, что список непуст. Пустой или отсутствующий файл подписи для
# читателя НЕ означает «проверять нечего»: это смена формы дома, и каждый из
# троих обязан отказать кодом 2, а не пропустить копирование. Пусто не ноль.
#
# Формат: по одному относительному пути на строку, пустые строки и строки,
# начинающиеся с #, игнорируются. Путь должен быть ФАЙЛОМ (не каталогом).
