# Сколько правок tweakcc ПРОБУЕТСЯ на названной версии. Число здесь ОДНО, и это
# следствие: у суммарного счёта было ДВА ВЛАДЕЛЬЦА, и теперь каждая величина
# живёт в доме СВОЕГО владельца -- слой кода здесь, пол слоя накладок в доме
# tweakcc машины.
#
#   * СЛОЙ КОДА -- правки самого бинарника, и считаются здесь ПОПЫТКИ, а не
#     удачи. Строка печатается при любом исходе: «✓ Имя — описание» легло,
#     «✗ Имя — описание» не легло, «○ Имя» выключено конфигурацией дома
#     tweakcc (кружки видны только под --show-unchanged, и конвейер зовёт
#     tweakcc с этим ключом). Владелец числа попыток ОДИН -- реестр правок
#     нашего форка; от машины оно не зависит. Гейтится ДВУСТОРОННЕ.
#
#     Почему попытки, а не галочки. У числа ГАЛОЧЕК владельцев ТРИ: реестр
#     форка (сколько правок пробуется), версия апстрима (какие не легли --
#     их разбирает поимённо tools/tweakcc-known-misses.txt) и дом tweakcc
#     КОНКРЕТНОЙ МАШИНЫ (какие выключены конфигурацией -- их разбирает
#     объявление catalyst-expected-off.txt рядом с config.json того дома).
#     Галочки -- остаток после вычитания двух чужих множеств, и остаток этот
#     приписывался ВЕРСИИ. На втором контуре тот же кит и та же версия дали
#     «объявлено 13, легло 14», а всей разницей была одна правка Thinker
#     symbol chars, включённая там пользовательским символом спиннера. Отсюда
#     ложные отказы на любой второй машине -- и потому предмет двери сменён.
#   * СЛОЙ НАКЛАДОК -- тексты промтов (строки под секцией «System Prompts»
#     вывода форка; слой опознаётся СЕКЦИЕЙ, а не префиксом имени: имя накладки
#     берётся из frontmatter файла оператора, и кит им не владеет). Владелец
#     ДРУГОЙ: каталог накладок ПОЛЬЗОВАТЕЛЯ ~/.tweakcc/system-prompts/. Он
#     добавляет накладку -- число растёт, и дефекта в ките при этом нет
#     никакого. Гейтится ПОЛОМ: просадка -- отказ, рост -- никогда. ЗДЕСЬ ЕГО
#     НЕТ: пол снят с каталога ОПЕРАТОРА, и строка кита, несущая его, отказывала
#     бы на второй машине там, где просело только число накладок у человека. Дом
#     пола -- catalyst-prompt-floor.txt рядом с config.json того дома tweakcc, у
#     своего владельца, как и объявление выключенных правок.
#
# Что стоило разделения. Двери у этого счёта не было вовсе: число печаталось
# и ни с чем не сверялось -- это и есть находка #58, ради которой заведён
# этот дом. Первый набросок двери сверял ОДНО суммарное число равенством, и
# вот на чём он ломался. Прежние прогоны на 257 и 258 отдавали 13 легших --
# в профиле, где слой накладок не ложился вовсе; сегодня на тех же образах
# ложится 13 кода и 20 накладок, то есть 33 суммарно, хотя кит и апстрим с
# тех пор не менялись. Суммарная дверь, объявленная по прежнему числу,
# отказала бы «легло 33 при объявленных 13» -- и была бы формально права:
# выросла половина, которая принадлежит ЧЕЛОВЕКУ, каталогу накладок
# пользователя, а дефекта в ките при этом нет никакого. Отказа такого НЕ
# БЫЛО -- случиться ему было негде, двери не существовало; разрыв я увидел
# руками, сверяя печатаемый счётчик с прежними прогонами.
#
# Зачем отдельный дом, когда рядом лежит дом непроходов. Предметы разные.
# Там -- поимённые правки, которые ПРОБОВАЛИСЬ и не легли (строка «✗ »).
# Здесь -- КОЛИЧЕСТВО попыток («✓ » + «✗ » + «○ »). Различие не косметическое:
# когда правки не пробуются вовсе, крестиков не появляется ни одного, и для
# сверки непроходов такая версия выглядит чистой. Ровно так 2.1.257 отдала 13
# легших при соседском уровне 33-36 -- и вердикт свипа сказал «красных нет».
# Третий сосед -- объявление выключенных правок (catalyst-expected-off.txt в
# доме tweakcc): там поимённые «○ », и владелец у них не версия, а машина,
# поэтому и дом объявления не здесь, а рядом с конфигом того дома.
#
# Двери:
#   * попыток кода измерено МЕНЬШЕ объявленного -- отказ (слой просел
#     молча: попытка исчезает из вывода целиком, не оставляя крестика);
#   * попыток кода измерено БОЛЬШЕ объявленного -- тоже отказ: объявление
#     пережило свою причину, реестр форка вырос, а запись прикрывала бы
#     провал;
#   * двери ПОЛА накладок стоят на прежнем месте в конвейере, но читают строку
#     версии в catalyst-prompt-floor.txt дома tweakcc: меньше пола -- отказ,
#     «нет-слоя» требует двустороннего нуля (без этого маркера версия без
#     данных апстрима осталась бы без зубов вовсе), не число и не «нет-слоя» --
#     отказ. Файла нет вовсе И слоя не измерено -- сходится молчаливым NOTE:
#     свежая машина и пустой дом клона свипа краснеть не должны;
#   * строки для версии НЕТ             -- отказ с ОБОИМИ измеренными
#     числами и готовой строкой для вставки. Это и есть требуемая
#     дисциплина: один взгляд человека за версию. Именно его не хватило на
#     падении 33 -> 14.
#
# ТРЕТИЙ канал -- накладка, чей сохранённый текст разошёлся с образом. Она не
# печатает ни галочки, ни крестика: tweakcc говорит «Could not find system
# prompt "X" in cli.js». Сверка непроходов читает только крестики и этих
# промахов не видела вовсе -- на 2.1.259 их две дюжины. Теперь они СЧИТАЮТСЯ
# и поимённо НАЗЫВАЮТСЯ в логе, но намеренно НЕ гейтятся: число растёт и от
# поломки форка, и от того, что человек добавил накладку с разошедшимся
# текстом, -- потолок воспроизвёл бы ровно тот дефект двух владельцев,
# который здесь разбирается. Регресс ловится с другой стороны: полом легших.
#
