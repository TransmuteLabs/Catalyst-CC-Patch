# Сколько правок tweakcc ЛОЖИТСЯ на названной версии -- ДВУМЯ числами, потому
# что у одного суммарного числа ДВА ВЛАДЕЛЬЦА.
#
#   * СЛОЙ КОДА -- правки самого бинарника (строки «✓ Имя — описание»).
#     Владелец один: версия апстрима, скрещённая с нашим форком tweakcc.
#     Меняется только тогда, когда меняется одно из двух, и меняется у всех
#     одинаково. Гейтится ДВУСТОРОННЕ.
#   * СЛОЙ НАКЛАДОК -- тексты промтов (строки «✓ <Тип>: Имя», где тип один из
#     Agent Prompt / Data / Skill / System Prompt / System Reminder /
#     Tool Description / Tool Parameter). Владелец ДРУГОЙ: каталог накладок
#     ПОЛЬЗОВАТЕЛЯ ~/.tweakcc/system-prompts/. Он добавляет накладку -- число
#     растёт, и дефекта в ките при этом нет никакого. Гейтится ПОЛОМ:
#     просадка -- отказ, рост -- никогда.
#
# Что стоило разделения. Двери у этого счёта не было вовсе: число печаталось
# и ни с чем не сверялось -- это и есть находка #58, ради которой заведён
# этот дом. Первый набросок двери сверял ОДНО суммарное число равенством, и
# вот на чём он ломался. Прежние прогоны на 257 и 258 отдавали 13 легших --
# в профиле, где слой накладок не ложился вовсе; сегодня на тех же образах
# ложится 13 кода и 20 накладок, то есть 33 суммарно, хотя кит и апстрим с
# тех пор не менялись. Суммарная дверь, объявленная по прежнему числу,
# отказала бы «легло 33 при объявленных 13» -- и была бы формально права:
# выросла половина, которая принадлежит ЧЕЛОВЕКУ, каталогу накладок
# пользователя, а дефекта в ките при этом нет никакого. Отказа такого НЕ
# БЫЛО -- случиться ему было негде, двери не существовало; разрыв я увидел
# руками, сверяя печатаемый счётчик с прежними прогонами.
#
# Зачем отдельный дом, когда рядом лежит дом непроходов. Предметы разные.
# Там -- поимённые правки, которые ПРОБОВАЛИСЬ и не легли (строка «✗ »).
# Здесь -- КОЛИЧЕСТВО легших («✓ »). Различие не косметическое: когда правки
# не пробуются вовсе, крестиков не появляется ни одного, и для сверки
# непроходов такая версия выглядит чистой. Ровно так 2.1.257 отдала 13
# легших при соседском уровне 33-36 -- и вердикт свипа сказал «красных нет».
#
# Двери:
#   * кода измерено МЕНЬШЕ объявленного -- отказ (слой просел молча);
#   * кода измерено БОЛЬШЕ объявленного -- тоже отказ: объявление пережило
#     свою причину, правки снова ложатся, а запись прикрывала бы провал;
#   * накладок измерено меньше ПОЛА     -- отказ; больше пола -- зелено;
#   * пол записан как «нет-слоя»        -- отказ на ЛЮБОЕ ненулевое число
#     легших накладок И на любое ненайденное: слой объявлен отсутствующим,
#     а он ожил. Без этого маркера версия без данных апстрима осталась бы
#     без зубов вовсе;
#   * пол не число и не «нет-слоя»      -- отказ: строка сломана;
#   * строки для версии НЕТ             -- отказ с ОБОИМИ измеренными
#     числами и готовой строкой для вставки. Это и есть требуемая
#     дисциплина: один взгляд человека за версию. Именно его не хватило на
#     падении 33 -> 14.
#
# ТРЕТИЙ канал -- накладка, чей сохранённый текст разошёлся с образом. Она не
# печатает ни галочки, ни крестика: tweakcc говорит «Could not find system
# prompt "X" in cli.js». Сверка непроходов читает только крестики и этих
# промахов не видела вовсе -- на 2.1.259 их две дюжины. Теперь они СЧИТАЮТСЯ
# и поимённо НАЗЫВАЮТСЯ в логе, но намеренно НЕ гейтятся: число растёт и от
# поломки форка, и от того, что человек добавил накладку с разошедшимся
# текстом, -- потолок воспроизвёл бы ровно тот дефект двух владельцев,
# который здесь разбирается. Регресс ловится с другой стороны: полом легших.
#
# Уровень привязан к ВЕРСИИ и на соседнюю не переносится: данные апстрима у
# каждой свои.
#
# Слепая ручка CLAUDE_PATCH_ALLOW_TWEAKCC_FAILURES=1 гасит и эту дверь -- она
# и так означает «строю без гарантий слоя», -- но гашение ОБЪЯВЛЯЕТСЯ в лог.
#
# Формат: четыре поля через ТАБУЛЯЦИЮ.
#   <версия>	<уровень кода>	<пол накладок|нет-слоя>	<причина/происхождение чисел>

# Строки вписываются ИЗМЕРЕННЫМИ числами (их печатает сам конвейер строкой
# «tweakcc: легло N правок (кода X, промтов Y)»), а не по памяти: заявленное
# число, взятое из головы, прикрыло бы ровно тот провал, ради которого дом
# заведён. Пол накладок ставится по измеренному числу: он и означает «столько
# у человека уже ложилось, меньше -- регресс».
