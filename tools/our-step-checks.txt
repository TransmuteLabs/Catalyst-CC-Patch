# Дом карты «шаг -> проверки» (свойство КИТА, не решение оператора).
#
# Назначение: реестр выключенных шагов (tools/our-steps-off.txt) несёт решение
# оператора, а проверяющая сторона конвейера обязана ЗНАТЬ о выключенном шаге:
# без строки карты компоновка молча выключит шаг, его проверки пойдут обычным
# путём и упадут «предмета нет» без объяснения, мимо машинерии вердиктов
# реестра (note-off / note-predates / fail-stale / fail-carrier). Гейт
# tools/step-checks.py --gate отказывает ДО компоновки, называя шаг.
#
# Формат: три поля через '|' (пробелы вокруг полей сняты):
#   <имя шага ровно как в step('…')> | <id обработчика> | <имена проверок через ';'>
#
# Поле проверок, равное '-', -- ОБЪЯВЛЕННОЕ отсутствие проверок: норма, а не
# забытая строка -- дельта обязана быть объявляемой и отличимой от поломки.
# Id обработчика называет verdict-функцию проверяющей стороны; обработчик,
# неизвестный коду, -- отказ прибора: он обязан заставить волну, добавляющую
# запись реестра, добавить и обработчик.
#
# КОНСТРЕЙНТ: пустая карта, отсутствующий файл и файл из одних комментариев --
# ОТКАЗ ПРИБОРА (в отличие от реестра выключений): карта -- свойство КИТА, её
# пустота означает потерю данных, а не решение оператора. Неразобранная строка
# и две строки на одно имя -- отказ с номером строки.
