## Обработка протухшего владельца

Критерий ОДИН и он не по возрасту: pid пуст, либо `kill -0` не проходит, либо
`lstart` не совпал с записанным. Перед чтением pid — до 5 раз `sleep 0.2`.

- `claude-patch-all.sh:420-423` — снос и повторный `mkdir`; живой владелец не
  трогается, `exit 3` (:425-427).
- `probes-sync.sh:430-433` — то же для `$SYNC_LOCK.d`; живой → `exit 3` (:437-438).
- `sweep.sh:472-473` — ТОЛЬКО `sweep.pgid` (pid-файл остановки, не `flock`), условие
  по возрасту `find -mtime +0` либо mtime из будущего (:464-466). Моложе суток —
  `continue`, файл не удаляется.
- Стенд `probes-sync-bench.sh` сажает состояния, при которых ветка обязана
  сработать (:411, :416, :420, :424); сам каталог не удаляет.

НЕ эта категория: занятый `flock` НИ В ОДНОМ носителе не чистится — только отказ.

протухания нет.
