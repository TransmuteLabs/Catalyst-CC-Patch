## 2. Отказ по посылке (refuse-with-proof): §5 × §9 × §10.2 несовместимы

Бриф §1 утверждает, что третья копия ядра схлопывается циклом `:4415-4419` и

зелёные» и «правка §2 не роняет ни одну из 119». Оба утверждения опровергаются
побайтовыми пинами блока `checks`, который §9 запрещает трогать
(«ТОЛЬКО :6087 … блок `checks` и `EXPECTED_CHECKS` НЕ трогать — это волна T2»):

Семь проверок требуют РОВНО ДВА блока `/*__ccProbe0*/…/*__ccProbe1*/` либо
РОВНО ДВА `dirEnv:` — любой третий блок пробы (§5: `formBlock='/*__ccProbe0*/'
+ core + formCall + '/*__ccProbe1*/'`) и любой formCall с
`dirEnv:process.env.CLAUDE_PROBES_DIR` (§3.1, обязательное поле) делают их
красными. Сырой вывод `grep -n` по `claude-patch-all.sh` (дерево `9db078a`):

```

3840:    if len(ends) != 2 or len(starts) != 2:   # 'judge rides the tool, watcher the dispatcher' (:4633)
```
