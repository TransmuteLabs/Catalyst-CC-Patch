Бриф предписывает пробу `: "${__NO_SUCH_VAR:?проба часового}"` в середину

**Проба §5.3 дословно, реальный файл (после починки).** Проба вставлена

```
Гвард получил `$?` = 1 в трапе и корректно пропустил ненулевой код: стало
1, а не 2 (§5.3 ждёт 2).

**Та же проба на ДОСЛЕВА-копии** — в единственном пути до-правки с

== badsub rc=0 | TRAP SAW __rc=0 (DONE=1) | continued=1
```

По формам:
1. `set -u` unbound и `${x:?msg}` — фатальны, но НЕ маскируются: трап
   видит `$?`=1, вызывающий видит 1. Утверждение §0 «трап исполняется,
   `$?` внутри него — ноль» для них на bash 3.2.57 arm64 не
   воспроизводится.
2. Bad substitution — НЕ фатальна: ошибка печатается, скрипт продолжает
   исполнение до штатного конца (rc 0 — от продолжения, не от ложного
   нуля из-под трапа). Часовой эту форму поймать не может конструктивно:
   обрыва нет, конец достигается штатно и объявляет `__DONE=1`.

Итог: §5.3 невыполним ни для одной из трёх форм, перечисленных в опоре
брифа (§0), на текущей машине. Попытка №1 по стоп-правилу — матрица форм
собственного §0 + дословная проба §5.3 на реальном файле ДОСЛЕВА/ПОСЛЕ —
исчерпана; копание в механизм маскировки (был ли он когда-либо, при каком
содержимом трапа/контексте) — уже диагностика, не делаю.

Правка файла НЕ откачена: она предписана §1–§3, дословна по образцу,
статический гейт правила 3 текстовый и зелёный, поведение и 9/9/9 зубов
сохранены. Оценка «нужен ли часовой при непроигравшейся посылке» —
решение контроллера.

## 5. Concerns (флаг, не правка)

  stderr) — отдельный класс «молчащего» зелёного прогона, часовым не
  лечится; бриф его посылкой §0 считает фатальным. Если он реальен в
  бою — нужна иная защита, вне рамок дорожки A.
- По образцу добавлены `trap 'exit 130' INT` / `trap 'exit 143' TERM` —
  у bun-drift раньше сигнальных трапов не было; при смерти от сигнала
  вызывающие теперь увидят 130/143 вместо «умирания от сигнала». Зубов
  на это ни у кого нет; форма отмечена.
- `tools/bun-drift.sh` нёс чужие невыпущенные правки до меня (`M` в
  git status); вставки легли поверх, ничего не откатывал.
