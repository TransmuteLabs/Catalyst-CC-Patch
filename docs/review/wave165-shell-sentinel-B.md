`set -u` + `:?` + гвард → TRAP_SAVED=1 OUTER=1
`set -eu` + `:?` + гвард → TRAP_SAVED=0, печать `ОТКАЗ: оборвался`, OUTER=2
`set -eu` + `:?` + старый трап `rm -rf` без `exit` → OUTER=0

Добавлять `set -e` в `reap-heavy.sh` бриф не велел (и для прополки дисков это было бы расширение предмета). См. adjudication.

## 5. Adjudication requests
