## Корень, а не восемь дыр

Пин делается ВРУЧНУЮ, полем в свипе, а стадий никто не перечисляет. Значит
следующая заведённая стадия снова приедет непиняемой ПО УМОЛЧАНИЮ — ровно так
приехал «Гейт наследования замка» волны 34b, свой собственный непин. Починка
только восьми оставляет корень живым.

## Полный фикс

1. **Зелёная строка раскатки** — единственная, которой нет. Печатать в
   `scripts/probes-sync.sh` на ветке `--diff` с кодом 0, с числом сверенных
   файлов (число => владелец => гейт чисел => строка в `docnum-mutations.tsv`).

2. **Перепись стадий `tools/pipeline-stages.tsv`.** Колонки:
   `id` · `заголовок стадии как печатает echo "==> "` · `регексп подтверждения`
   · `регексп объявленного пропуска (может быть пуст)` · `условие, если стадия
   не в каждой сборке`. Условные стадии называют условие явно:
   `Fetching the unpacker` — мимо кэша; `Opening tweakcc's UI` — интерактив;
   `Refreshing model prices` — ручка `CLAUDE_PATCH_SKIP_MODELS`;
   `Installing a pristine Claude Code` — суффикс `${UPDATE_VER:+ …}`;
   `Cleaning old unpacker builds` — подстановка `$keep`;
   `Пол проверок ПРОПУЩЕН` — вторая ветка той же стадии.
   Заголовки с подстановками сверяются ПРЕФИКСОМ до первой `$`.

3. **Гейт переписи** (стадия конвейера, рядом с «Сверкой чисел»): множество
   `echo "==> "` в конвейере == множество строк переписи. Расхождение — отказ
   класса 4 («объявленное не сошлось с деревом»), обе стороны названы поимённо.
   Собственный положительный контроль на синтетике: стадия лишняя в коде,
   стадия лишняя в переписи, заголовок с подстановкой, пустой список.
   ЭТО и снимает корень: новая стадия без строки переписи не проходит сборку.

4. **Свип требует подтверждение КАЖДОЙ строки переписи** в логе версии.
   Красная причина называет стадию: `стадия «X» не оставила следа`.
   Условные стадии проверяются только когда их условие выполнено; объявленный
   пропуск засчитывается как ответ вызова (образец — `floor`).

5. **Зубы:** сценарии corpus-tools-bench + равнодлинные мутации на:
   расхождение переписи в обе стороны; пропавшее подтверждение в логе;
   засчитанный объявленный пропуск; условная стадия, чьё условие не выполнено,
   не краснит.

6. **Счётчики в трёх домах:** `EXPECTED_*`, README, D-строка
   `docnum-mutations.tsv`. `--anchors` прогоняется ДО конвейера.

ГРАНИЦА ОСЛАБЛЕНИЯ: колонка «условие» — не лазейка. Она не даёт стадии
проехать молча: строка в переписи обязательна ДЛЯ ЛЮБОЙ стадии, и пометка
«условная» — это записанное и читаемое человеком решение, а не умолчание.
Корень («стадия непиняема ПО УМОЛЧАНИЮ») снимается именно обязательностью
строки, а не тем, требует ли она следа в логе.
